# Last Seconds

Jogo web com estética retrô, menu de partida e ranking.

**Contexto:** Protótipo de jogo.  
**Tecnologias:** HTML, CSS e JavaScript.

## Visão do projeto

A entrada do jogo apresenta ações para iniciar uma partida, consultar ranking e acessar informações. Imagens, estilos, scripts e páginas complementares ficam em pastas separadas.

## Executar localmente

Clone o repositório e sirva os arquivos localmente. Com Python instalado:

```bash
git clone https://github.com/GuiPaicheco/LAST-SECONDS.git
cd LAST-SECONDS
python -m http.server 8000 --bind 127.0.0.1
```

Abra [http://127.0.0.1:8000/index.html](http://127.0.0.1:8000/index.html). Preserve as pastas de imagens, estilos e scripts. Recursos externos, quando usados pela página, podem exigir conexão com a internet.
